## 1. Re-checked the SEO audit against the live site
- Crawled all 73 live pages and confirmed every one of the 18 audit findings before fixing anything.
- **What the live site showed:**
  - 43 pages without an H1
  - 64 titles longer than 60 characters
  - 19 titles repeating the brand
  - 3 broken sitemap URLs and 15 pages missing from the sitemap
  - sideways scrolling on mobile
  - colour contrast errors on every tested page
  - Best Practices score 73–77

## 2. Fixed all 18 audit findings
Full details are in `docs/SEO-FIX-REPORT.md`.

**Headings and titles**
- Every indexable page now has exactly one H1.
- All titles are 60 characters or less, and the brand is no longer repeated.
- Short and mistyped meta descriptions rewritten, e.g. "counselling in in", "oonline", "clinets", "Bok".

**Sitemap and URLs**
- The sitemap is now built from real data, including blog posts from Firestore. It has 71 URLs, all working.
- Two badly named blog URLs moved to clean ones, with 301 redirects from the old URLs.
- The homepage URL is written the same way in the canonical, sitemap and structured data.

**Layout**
- No sideways scrolling on any screen from 320 to 1440 px.
- The desktop menu no longer runs off-screen on laptops; below 1280 px the hamburger menu is used.
- The contact page map shows on mobile again; it had been cut off.

**Accessibility**
- **Colour contrast:** a darker coral for small text, and a clearer focus outline.
- **Tap targets:** all at least 24 px.
- **Navigation aids:** skip-to-content link and screen-reader labels.

**Content**
- Removed placeholder text that was visible on the site: "Hero paragraph" on the homepage, "Replace this page… before launch", and "Placeholder entries".
- Therapy, case-study and training pages now show verified practice details (who leads the practice, where sessions happen, things to know first) and related links.
- The placeholder team page is hidden from Google until real details are added.
- Blog posts, service pages and case studies now link to each other, and four blog titles no longer compete with service pages.

**Security and speed**
- **Security headers:** Content-Security-Policy, nosniff, X-Frame-Options, Referrer-Policy and Permissions-Policy.
- **Clarity consent banner:** Microsoft Clarity now loads only after the visitor clicks "Allow". The privacy policy now mentions Clarity.
- **Faster pages:** the homepage, blog and gallery are cached instead of rebuilt on every visit; Google Analytics loads after the page is ready; an unused font file was removed.
- **New site assets:** branded 404 page, favicon and app icons, social-share image and logo.

## 3. Built test scripts and reports
- **Scripts in `scripts/seo/`:**
  - `npm run seo:check`: SEO crawler
  - `npm run seo:browser`: mobile and accessibility checks
  - `npm run seo:consent`: consent banner and security policy checks
  - `npm run seo:lighthouse`: Lighthouse scores
- **Reports:** `docs/SEO-FIX-REPORT.md` and `docs/SEO-VALIDATION-REPORT.md`.

## 4. Fixed the "Allow / No thanks" buttons
- **Cause:** the new security policy blocked the JavaScript that `npm run dev` uses, so nothing on the page was clickable locally.
- **Fix:** the policy is relaxed only in development; production is unchanged.
- **Result:** tested in both dev and production.

- **Finding 2:** the Vercel Firewall is active on the project and may be linked to those errors, so it needs checking in the Vercel dashboard.
- **Finding 3:** old WordPress URLs still returned 404.
